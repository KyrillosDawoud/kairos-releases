# Kairos releases

Installers and update metadata for Kairos, the desktop app that brings your calendar, inbox,
money, classes and notes into one place.

## Download

Windows 10 and 11, 64-bit.

- **Preview**, the current build from the main branch:
  [Kairos-preview-x64-setup.exe](https://github.com/KyrillosDawoud/kairos-releases/releases/download/preview/Kairos-preview-x64-setup.exe)
- **Releases**, versioned builds that update themselves: the
  [Releases page](https://github.com/KyrillosDawoud/kairos-releases/releases/latest).

Builds are not code signed yet. Windows shows "Windows protected your PC". Click More info,
then Run anyway. The installer runs for your account only and needs no administrator rights.

## Updates

Installed releases check this repository for `latest.json` and update themselves. Preview
builds do not update themselves. Download the newest preview from the link above.

## Source

The source code is private. This repository holds only installers and update metadata.
